# 📦 Continental Shop Inventory Dashboard

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Power Query
- Conditional Formatting
- Slicers

## 📊 Project Overview
This project analyzes inventory performance across four Continental Shop branches (Adum, Asokwa, Bantama, and Suame) using Microsoft Excel. The dashboard tracks opening stock, stock received, stock sold, and remaining inventory to support inventory management and restocking decisions. It provides interactive visualizations that help identify stock shortages, surplus inventory, and branch performance. 

## 📚 What I Learned
- Cleaned and combined multiple inventory datasets into a single analysis table.
- Built interactive dashboards using Pivot Tables, Pivot Charts, and Slicers.
- Applied conditional formatting to identify products requiring urgent restocking.
- Created KPIs to monitor branch performance and inventory levels.
- Transformed business data into actionable insights and recommendations. 

## 📈 Key Insights
- Bantama recorded the highest inventory level (591 units) and maintained the healthiest stock position.
- Asokwa had the lowest remaining inventory (370 units) and required the most urgent replenishment.
- Adum and Bantama recorded the highest transaction activity.
- Suame had the lowest transaction volume but maintained high inventory, indicating slower stock movement.
- Sports Sneakers and Men's Polo T-Shirt required immediate restocking in some branches.

## 💡 Business Recommendations
- Prioritize restocking products classified as **Re-stock Now**.
- Increase inventory allocation to branches experiencing frequent stock shortages.
- Monitor products in the **Low Stock** category before they become out of stock.
- Use Bantama's inventory management approach as a benchmark for other branches.
- Introduce promotional activities for branches with slower inventory turnover, such as Suame.
